Codex 安装与配置教程

系统要求

  • Windows 10 或 Windows 11
  • Node.js 22+
  • npm 10+
  • 正常网络连接

前置步骤

安装 Git Bash，访问 Git - Downloads 下载对应系统版本，全程默认下一步完成安装。

1. 安装 Node.js

访问 Node.js 官网，下载并安装最新 LTS 版本。

2. 安装 Codex

打开 CMD 或 PowerShell，执行命令：

bash 
npm install -g @openai/codex

3. 验证安装

终端内运行以下指令，查看版本：

bash 
codex --version

配置 API

  1. 进入用户目录下的 .codex 文件夹，示例路径：C:\Users\testuser\.codex（testuser 替换为你自己的用户名）
    💡 提示：看不到目录请在文件资源管理器开启「显示隐藏的项目」。
  2. 若无 .codex 文件夹，手动创建，并在其中新建 config.toml、auth.json 两个文件。
  3. 填入对应配置：

auth.json

json 
{"OPENAI_API_KEY": "nb-xxx"}

⚠️ 将 nb-xxx 替换为你申请的真实密钥

config.toml

model_reasoning_effort 可选 high / medium / low，代表模型思考强度。

toml 
model_provider = "your-provider-name"
model = "gpt-5.5"
model_reasoning_effort = "high"
disable_response_storage = true
preferred_auth_method = "apikey"

[model_providers.api111]
name = "your-provider-name"
base_url = "https://api.lyn91r.cn/v1"
wire_api = "responses"

⚠️ model_provider 和 name 填你自己起的名字（英文或数字），两者需一致；model 填你申请到的模型名。

Claude Code 安装使用教程

Claude Code 是一个强大的 AI 编程助手，让您可以直接在终端中与 AI 协作编程。本教程将指导您完成安装和配置过程。

📋 系统要求

  • Node.js 版本 ≥ 18.0
  • 支持的操作系统：macOS、Linux、Windows (WSL)

🚀 快速开始 — 安装 Node.js

💡 提示：如果您已经安装了 Node.js 18.0 或更高版本，可以跳过此步骤。
bash 
# 安装 Node.js LTS 版本
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo bash -
sudo apt-get install -y nodejs

# 验证安装
node --version
bash 
# 安装 Xcode 命令行工具
sudo xcode-select --install

# 安装 Homebrew（如果尚未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 通过 Homebrew 安装 Node.js
brew install node

# 验证安装
node --version

安装 Claude Code

使用 npm 全局安装 Claude Code：

bash 
npm install -g @anthropic-ai/claude-code

# 验证安装
claude --version

配置并开始使用

获取必要的配置信息

您需要准备两个重要的配置项：

配置项说明获取方式
ANTHROPIC_AUTH_TOKENAPI 认证令牌自己申请来的令牌
ANTHROPIC_BASE_URLAPI 服务地址使用 https://api.lyn91r.cn

启动 Claude Code

在您的项目目录下运行：

bash 
# 进入项目目录
cd your-project-folder

# 设置环境变量
export ANTHROPIC_AUTH_TOKEN="nb-..."
export ANTHROPIC_BASE_URL="https://api.lyn91r.cn"
export API_TIMEOUT_MS=300000

# 启动 Claude Code
claude
powershell 
# 进入项目目录
cd your-project-folder

# 设置环境变量
$env:ANTHROPIC_BASE_URL = "https://api.lyn91r.cn"
$env:ANTHROPIC_AUTH_TOKEN = "nb-..."
$env:API_TIMEOUT_MS = "300000"

# 启动 Claude Code
claude
cmd 
REM 进入项目目录
cd your-project-folder

REM 设置环境变量
set ANTHROPIC_BASE_URL=https://api.lyn91r.cn
set ANTHROPIC_AUTH_TOKEN=nb-...
set API_TIMEOUT_MS=300000

REM 启动 Claude Code
claude

❓ 常见问题解答

Q: 遇到 "Invalid API Key / Please run /login" 错误？

A: 这表明 Claude Code 未检测到环境变量。请检查：

  • 是否正确设置了 ANTHROPIC_AUTH_TOKEN 和 ANTHROPIC_BASE_URL
  • 环境变量值是否正确（令牌以 sk- 开头）
  • 如果使用了永久配置，是否重启了终端
Q: 为什么显示 "offline" 状态？

A: Claude Code 通过连接 Google 来判断网络状态。显示 "offline" 不影响正常使用，只是表明无法连接到 Google。

Q: 为什么浏览网页的 Fetch 会失败？

A: Claude Code 在访问网页前需要调用 Claude 服务进行安全检查。您需要：

  • 保持稳定的国际互联网连接
  • 必要时使用全局代理
Q: 请求总是显示 "fetch failed"？

A: 可能是网络环境导致的问题。解决方案：尝试使用代理工具。

Q: API 报错如何处理？

A: 可能是转发代理不稳定导致的，建议：

  • 退出 Claude Code（Ctrl+C）
  • 重新运行 claude 命令
  • 如果问题持续，请稍后再试
Q: 网页登录错误？

A: 尝试清除本站的 Cookie，然后重新登录。
