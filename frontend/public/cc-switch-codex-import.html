导入流程
由 CC Switch 负责最终确认和写入。

          

            
1
生成官方深链使用 V1 provider import 协议，参数经过 URL 编码。

            
2
唤醒 CC Switch操作系统可能先询问是否允许打开 ccswitch://。

            
3
在 CC Switch 中确认CC Switch 会展示导入预览，点击“导入”后才会写入本机配置。

          

          
深链可能包含 API Key。示例页仅用于演示，请勿把真实深链粘贴到公开聊天、工单或日志中。
